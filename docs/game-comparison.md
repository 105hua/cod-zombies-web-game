This is a representative comparison, not a map-by-map specification. Each evidence link leads to a chapter with direct sources. “Absent” refers to the scoped map/system, not every possible secret, mod, or special playlist. Release-era sources are not current-patch verification.

## The recurring core and the changing rules

**Synthesis:** the stable pattern is fighting rounds, earning resources, buying improvements and useful access, then sustaining survival under greater pressure. The unstable parts are **what the player starts with, how combat earns money, which upgrades exist, what a down costs, and how the run can end**.

## Named Survival versus other formats

| Name                                  | Relationship to this research                                                                                                                       |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **BOII Survival**                     | The central classic named-mode example: compact arenas and deliberately different facility availability.                                            |
| **BOII TranZit**                      | Related round-based Zombies, but with travel, buildables, and different setup. Do not copy its rules into Town Survival just because both use Town. |
| **BOII Grief**                        | Competitive teams try to outlast one another. Not the ordinary cooperative baseline.                                                                |
| **BO4 Classic**                       | Baseline round-based comparison here; difficulty must still be stated.                                                                              |
| **BO4 Rush / Gauntlet / Mutations**   | Alternate pacing, fixed challenges, or custom rules, rather than interchangeable Survival settings.                                                 |
| **BO6 Standard / Directed**           | Standard is the endurance baseline; Directed guides quest progression and uses round caps.                                                          |
| **BO7 Survival / Standard**           | Named Survival confines combat to an adapted location; Standard's larger-map quest experience is distinct.                                          |
| **Outbreak / Modern Warfare Zombies** | Outside this bounded-arena round-based comparison; not evidence for its normal round-clear loop.                                                    |

## Differences that most affect a typical run

### 1. The same action can have a different economic purpose

In classic games, weak repeated hits can finance progression. BO4 limits the ordinary reward available from a zombie's health; Cold War and BO6 emphasize kills and critical kills. Consequently, “use the weakest gun to build points” is not timeless advice. [Mechanics](./mechanics-and-economy.md)

### 2. Upgrade availability is part of map identity

Original Nacht, BOII Bus Depot, BOII Farm, and BOII Town are useful counterexamples to a universal feature list. The first two lack perks and PaP; Farm adds perks; Town includes both. These maps still support Survival. In contrast, the BO7 Vandorn Farm guide explicitly expects multiple modern upgrade systems. [Classic](./classic-survival.md), [BO7](./black-ops-7-survival.md)

### 3. “Pack-a-Punch again” does not mean the same thing everywhere

BOIII's alternate-ammo repacking, BO4's bounded repeated damage upgrades, and Cold War/BO6's tiered upgrades are distinct. Modern rarity is another track, not simply a different name for PaP. [BOIII/BO4](./black-ops-3-and-4.md), [Modern](./modern-survival.md)

### 4. Survival power increasingly begins before the match

Classic map knowledge and in-match purchases remain important, but later loadouts, consumables, skill upgrades, and Augments change the starting conditions. **Synthesis:** comparing how long two players survive without considering those conditions can obscure major differences in their available tools. [BOIII/BO4](./black-ops-3-and-4.md), [Modern](./modern-survival.md)

### 5. Downing is not a universal inventory reset

Revival, bleedout, next-round return, perk loss, solo self-recovery, and special exceptions are separate rules. Quick Revive changes meaning across the sample. A recovered player may be alive but still need to rebuild enough protection to survive the next encounter. [Classic](./classic-survival.md), [BOIII/BO4](./black-ops-3-and-4.md), [Modern](./modern-survival.md)

### 6. Endurance, quest completion, and exfil are different goals

A high-round attempt need not finish a story quest. Optional exfil in Cold War/BO6 adds a successful way to leave, but is itself dangerous. Conversely, BO7's named Survival case removes the quest journey without removing round-based upgrading. No single ending rule fits every title. [Match flow](./match-flow.md)

## Practical reading rule

Before treating a statement as a game rule, identify **game → original/remake → map → mode → solo/co-op → difficulty/version**. Missing any of these can turn a true observation about one match into a false franchise-wide rule. These documents intentionally leave exact simulation constants out where the literature does not establish them reliably.
